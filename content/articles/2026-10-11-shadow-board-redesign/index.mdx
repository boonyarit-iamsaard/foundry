## Where I overrode it

{/* - Audience balance: mid-build he stopped it, because the build leaned toward hiring teams while freelance clients had equal weight. */}
{/* - Portrait: he asked for his face to matter much less, then suggested the header avatar. When the finish reviewer wanted the portrait back because the original plan had it, his request held and the brief was amended. */}
{/* - Prose headings: the approved system set article headings in uppercase Big Shoulders. Seeing a real article, he moved them to Barlow in sentence case, because full-sentence headings shouted. */}
{/* - Also his: header alignment, scrollbar gutter. */}

## Layered review

{/* Each layer caught what the others couldn't. */}
{/* - Him, on a phone. Reviewing the preview, he screen-recorded the mobile drawer closing right after it opened. */}
{/* – Live since June 28: a dependency-modernization commit added the drawer's own open state to a route-change effect to satisfy the exhaustive-deps lint rule, so opening the drawer scheduled its close. */}
{/* – Lint, types, tests and every review agent had passed over it. It predates the redesign; the redesign's review surfaced it. */}
{/* – A cloud agent wrote the fix and its before/after Playwright check. */}
{/* - The two-axis agent review (standards and spec, in parallel), run after the redesign commit. Lint and type-check passed throughout; all of this was invisible to tooling: */}
{/* – Accessibility: outline-none on buttons, inputs and textareas overrode the global focus ring, so the submit button showed no keyboard focus. The card's ring lit up when any link inside it was focused. */}
{/* – Spec drift: static slots (contact, resume) lifted on hover; code type and the Maintenance chain-line dash drifted from DESIGN.md; two slots and a night input border were undocumented. */}
{/* – Copy: the categorized tool list; a bare "status". */}
{/* – Images: a 205KB PNG cover with no provenance; session notes and a private quote in the design brief (scrubbed). */}
{/* – Code: dead logo icons, an untested slotCode that silently returned P-00, repeated helpers. */}
{/* – A worry that was wrong: drafts leaving gaps in slot numbering. Velite already strips drafts in production, so nothing changed. Checked before acting. */}
{/* – Sonar then flagged &:hover nested in a Tailwind @utility; fixed with @variant hover. */}
{/* - The critique and polish pass: the contact call hung at the end of every article and project (the author slot). */}
{/* - CodeRabbit: aria-pressed on a link; also empty filter state, aria-current, required fields, refocus after "Send another". */}
{/* - Closer: the CodeRabbit finding he declined. It asked for the branch history to be rewritten to remove a private chat quote. */}
{/* – The agent worked out why that wouldn't help: squash merges keep the commit out of main, and GitHub keeps PR refs anyway. */}
{/* – He checked the reasoning and declined. His call on the agent's reasoning, not his own argument. Don't say what the quote was. */}
