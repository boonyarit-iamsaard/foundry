## My Journey

Before I wrote software, I worked as an aircraft mechanic. Maintenance runs on procedure: a task card for every job, a torque value for every fastener, a signature for every step, and a tool count before the aircraft goes back into service. Nobody takes "it should be fine" as an answer.

When the pandemic changed everything, I taught myself full-stack development. While I was still in the hangar, I built an internal system for my department in Next.js and TypeScript. That project is where solving problems with code got hold of me.

## Current Focus

I work as a Software Engineer across the backend, the web and mobile. Most days that means designing and building server-side services in Node.js, Nest.js and Spring Boot, the React and Next.js interfaces that sit on top of them, and mobile apps in React Native.

## How I Work

The hangar habits came with me. I break work into small steps I can verify before moving on. I write tests for the behaviour that matters, so the next person can change the code without guessing. I keep changes easy to review, because inspection only works on work that can be read. And I like a pipeline that refuses to ship anything that hasn't passed its checks.
